# Adicione Anexos GED à uma Solicitação via Eventos
---

Através do método **attachDocument** disponível na [hAPI](http://tdn.totvs.com/x/8uAlE), é possível adicionar anexos GED à uma solicitação através de [eventos workflow](http://tdn.totvs.com/x/htAlE). Neste exemplo, veja como buscar os documentos de uma pasta informada pelo usuário no formulário, e adicione à solicitação automaticamente.
