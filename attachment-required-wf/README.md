# Validando se foram adicionados anexos à uma solicitação
---

Neste exemplo, veja como verificar se foram adicionados anexos à uma solicitação. Existem duas formas de realizar essa validação. Baixe o projeto e veja como é fácil adicionar essa regra de negócio ao seu processo.

Saiba mais consultando nossa documentação [hAPI](http://tdn.totvs.com/x/8uAlE) de [Desenvolvimento de Eventos](http://tdn.totvs.com/x/EIl8B) consultando o método **listAttachments()**.
