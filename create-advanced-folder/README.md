# Criando pastas com #AtividadeDeServiço e #docAPI
---

Neste exemplo, veja como é fácil utilizar a atividade de serviço para criação de pastas no fluig ECM. A pasta criada terá as configurações de segurança definidas no formulário do processo.

Atenção: utilize este exemplo com o fluig 1.5.9 ou superior.

Para entender como é utilizada uma [Atividade de Serviço](http://tdn.totvs.com/pages/viewpage.action?pageId=237397494#Integra%C3%A7%C3%A3oass%C3%ADncronaviaprocessosworkflow-AtividadedeServi%C3%A7o), utiliando o recurso [docAPI](http://tdn.totvs.com/x/x_MlE) para manipulação de documentos, clique nos links.
