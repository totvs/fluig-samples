# Adicionando regras na visualização de documentos
---

Neste exemplo, confira como criar regras no evento beforeDocumentViewer buscando informações do documento que está sendo visualizado. Neste exemplo, caso a data de validade do documento seja igual à atual, o documento não será visualizado.

Acesse a página de [Eventos Documentos](http://tdn.totvs.com/x/udspE) para saber mais sobre este evento.
