# Adicionar cópia de linha pai x filho



## Caso de uso
Adicionar pelo formulário uma nova linha em uma tabela pai x filho a partir da cópia de outra linha desta tabela.


## Técnicas abordadas
- Criação de formuário
- Utilização do componente pai x filho
- Customização de formulário
- Manipulação dos registros da tabela pai x filho.
