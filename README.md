Smart Zoom: como preencher campos de zoom automaticamente
====================================================

Neste exemplo veja preencher campos de zoom automaticamente, utilizando o método ".add" do seu campo de zoom passando o objeto informado na definição do campo. O preenchimento automático pode ser executado em qualquer cenário, tendo em mãos todos os dados do objeto. Baixe este projeto e veja como é fácil automatizar o preenchimento de campos usando utilizando JavaScript!
