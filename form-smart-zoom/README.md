# Smart Zoom: como preencher campos de zoom automaticamente
---

Exemplo válido para versão 1.6.1 ou superior.

Neste exemplo veja como preencher campos de zoom automaticamente, utilizando o método ".add" do seu campo de zoom passando o objeto informado na definição do campo. 

O preenchimento automático pode ser executado em qualquer cenário, tendo em mãos todos os dados do objeto. 

Baixe este projeto e veja como é fácil automatizar o preenchimento de campos usando utilizando JavaScript!

Para obter mais informações acesse [Desenvolvimento de Formulários](http://tdn.totvs.com/x/U4l8B).
