# Exemplo de widgets para a instalação de Datasets, Formulários e Processos
---

Caso o seu app para a fluig Store precisar de algum componente do fluig como Dataset, Formulário ou Processos, esses componentes devem estar previamente criados no fluig.
Esse exemplo contém uma widget para cada componente: 

###### wizard-install-dataset
###### wizard-install-form
###### wizard-install-process

Ao gerar o pacote, o próximo passo é fazer o upload através da Central de Componentes. Após enviar o .ear, será necessário ativar o componente. Procure pelo código, que está no component.xml, faça a ativação, atualize a página(F5) e acesse as páginas criadas.
