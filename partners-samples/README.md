# Projetos
---

1. **add-copia-linha-paiXfilho**: Formulário com exemplo de cópia de linha de pai x filho.
2. **attachment-required-wf**: Validando se foram adicionados anexos à uma solicitação.
3. **create-advanced-folder**: Exemplo de utilização da atividade de serviço para criação de pastas no fluig ECM.
4. **document-attach**: Adicione anexos GED à uma solicitação via eventos.
5. **event-document-expiration-date-validation**: Adicionando regras na visualização de documentos.
6. **event-notification**: Exemplo de personalização dos eventos beforeSendNotification e afterSendNotification.
7. **evento-global-login-validacao-expiracao-senha**: Exemplo de personalização dos eventos afterUpdateUser e beforeLogin para um controle de expiração de senhas de usuários.
8. **form-mobile-mail**: Ao tocar no link de *e-mail* do usuário em formulários, será executado um aplicativo de *e-mail* instalado no *smartfone*.
9. **form-mobile-tel**: Exemplo de utilização do recurso de ligação telefônica em formulários do app mobile.
10. **form-mobile-waze**: Exemplo para Implementação de Geolocalização com o Waze.
11. **form-modal-datatable**: Exemplo de formulário com modal e dataTable.
12. **form-smart-filter**: Exemplo de como atualizar os dados de um campo *zoom* com valor preenchido em outro campo.
13. **form-smart-zoom**: Exemplo de como preencher campos de *zoom* automaticamente.
14. **interacting-with-copy-controlled-properties**: Interagindo com Propriedades de Cópia Controlada.
15. **component**: Modelo de componente para a fluig Store.
16. **onNotify**: Exemplos de implementação do Evento Global onNotify.
